# The FooBarQix Kata

## Task Summary
* Create a function that takes a non-negative integer
and returns a string.
* The function shall answer Foo for each number divisible
by 3, Bar if divisible by 5 and Qix if divisible by 7.
* For each digit 3,  or 7, Foo, Bar or Qix shall be added to
a number in the order of the number's apperance.

## Reference
* Find the original description here: [Coding Dojo](https://codingdojo.org/kata/FooBarQix)
* This kata shall be used to exercise test driven development ([TDD](https://en.wikipedia.org/wiki/Test-driven_development?wprov=sfti1)).
* I use `pytest` for testing. I recommend to work with a virtual
environment. Requirements for the test are these libraries: 
`pytest` and `pytest-cov`.
* The code is based on `python 3.14`.
